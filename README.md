# Logistics-Optimization-for-Delivery-Routes-FedEx-Using-MySql-

This project presents a data-driven optimization solution designed to evaluate and enhance delivery route efficiency, operational logistics, and cost performance within a regional delivery network. By combining structured MySQL database queries with Power BI interactive visualizations, the project provides end-to-end insights into driver performance, delivery delays, regional route volume, and cost-efficiency trade-offs.
